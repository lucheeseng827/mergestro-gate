# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

In short: be respectful and constructive. Harassment, personal attacks, and
discriminatory behavior are not tolerated, in issues, pull requests, or any
project space.

**Reporting.** Report unacceptable behavior privately to the maintainer (via the
contact on the GitHub profile, or a GitHub Security Advisory for sensitive
cases). Reports are handled confidentially; maintainers may warn, remove
content, or ban for violations.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
